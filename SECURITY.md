# Security Policy

## Reporting a vulnerability

Report security vulnerabilities privately through GitHub private vulnerability reporting for this repository:

https://github.com/dmlehinger-web/stranger-thoughts/security/advisories/new

Private vulnerability reporting is enabled. Use that form so the report stays private until a fix is published. Please do not open a public GitHub issue for a vulnerability.

The v2 design review, data inventory, and verification checklist live in [docs/SECURITY-REVIEW.md](docs/SECURITY-REVIEW.md). That document is the review artifact. It is not a deployed environment.
